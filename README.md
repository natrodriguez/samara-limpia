# Sámara Limpia — starter site

A zero-build static website starter for samaralimpia.org.

## Local preview
Open `index.html` directly in a browser, or run a simple local server.

## GitHub Pages
1. Create a repository.
2. Upload all files in this folder to the repository root.
3. In GitHub: Settings → Pages.
4. Choose “Deploy from a branch”, branch `main`, folder `/ (root)`.
5. Add `samaralimpia.org` as the custom domain when ready.

## Cloudflare Pages
1. Push this folder to GitHub.
2. In Cloudflare Pages, import the repository.
3. Framework preset: None.
4. Build command: leave blank.
5. Output directory: `/`.
6. Add the custom domain when ready.

## Content notes
Dates and disposal destinations are intentionally placeholders until locally verified.
